# Горздрав СПб: охотник за талонами

Скрипт следит за расписанием на портале «Горздрав» ([gorzdrav.spb.ru](https://gorzdrav.spb.ru)) и сам
записывает вас к врачу, как только появляется подходящий талон. Кто-то отменил запись, и талон висит
свободным несколько минут. Руками такой почти не поймать, а скрипт проверяет расписание раз в 2 минуты.
О каждой находке и каждой записи он пишет в Telegram.

Идею подсмотрели у московского [emias-slot-hunter](https://github.com/polinalamponi/emias-slot-hunter)
(ЕМИАС). Это отдельная реализация для Петербурга.

## ⚠️ Важно знать

- Инструмент **неофициальный** и не связан с Комитетом по здравоохранению СПб и порталом «Горздрав». Он
  работает через те же запросы, которыми пользуется сам сайт. Их могут изменить в любой момент,
  тогда скрипт перестанет работать. Используйте на свой риск.
- **Скрипт никогда ничего не отменяет.** Команды отмены в коде нет. Он умеет только записать на
  свободный талон, то есть сделать то же, что вы можете сделать на сайте руками.
- **Не уменьшайте интервал.** В коде зашит пол: не чаще одного цикла в минуту. Рекомендуемый
  интервал крона — 2 минуты. Городская система общая на всех.
- Записывает только того человека, чьи ФИО и дату рождения вы указали, и только в поликлинику, где у
  него есть карта. Это та же проверка, что на сайте.
- Каждая новая цель сначала работает **вхолостую**: ищет и сообщает, но не записывает. Боевой режим
  включается вручную, и только после 30 холостых циклов.
- Портал отвечает только с российских IP. С зарубежного сервера соединение не устанавливается.

## Что умеет

- Искать поликлиники, специальности, врачей и свободные талоны.
- Ловить талон по условиям: поликлиника, специальность, конкретные врачи или любой, диапазон дат, дни
  недели, время дня, «раньше чем», минимальный запас до приёма.
- Записывать сразу или только сообщать (холостой режим).
- Не записывать повторно: перед записью проверяет, нет ли у пациента уже записи к этой специальности.
- Не больше 2 записей в сутки на пациента. Запрос записи не повторяется: при обрыве связи скрипт
  ставит цель на паузу и просит проверить запись руками.
- Писать в Telegram о находках, записях, сбоях, а раз в сутки присылать строку «жив».

Пока не умеет:

- переносить существующую запись (у портала нет такой операции). Если найдётся талон раньше, скрипт
  сообщит, а отменить старую запись нужно самому;
- записывать по направлению.

## Установка

Нужен только Python 3.9+ без сторонних библиотек: macOS, Linux или любой VPS в России.

```bash
git clone https://github.com/grisupergood-a11y/gorzdrav-slot-hunter.git
cd gorzdrav-slot-hunter
mkdir -p ~/.config/gorzdrav && chmod 700 ~/.config/gorzdrav
cp examples/creds.example.json ~/.config/gorzdrav/creds.json
cp examples/goals.example.json ~/.config/gorzdrav/goals.json
chmod 600 ~/.config/gorzdrav/*.json
```

Заполните `~/.config/gorzdrav/creds.json`: ФИО и дату рождения пациента, как в полисе. Для уведомлений
добавьте токен бота от [@BotFather](https://t.me/BotFather) и свой chat_id. Если Telegram не настроен,
сообщения печатаются в терминал.

Личные данные хранятся только у вас в `~/.config/gorzdrav/` и уходят только на gorzdrav.spb.ru, так же
как при записи через сайт.

## Как пользоваться

```bash
# 1. Найти поликлинику, специальность и врача
python3 gorzdrav.py lpus --find "№27"                 # id поликлиники
python3 gorzdrav.py specs --lpu 1                   # специальности, сколько свободных, ближайшая дата
python3 gorzdrav.py doctors --lpu 1 --spec 92134153       # врачи
python3 gorzdrav.py slots --lpu 1 --doctor 3028      # талоны

# 2. Проверить, что портал находит пациента (только чтение)
python3 gorzdrav.py patient --lpu 1
python3 gorzdrav.py my --lpu 1                      # ваши предстоящие записи

# 3. Описать цель в ~/.config/gorzdrav/goals.json и прогнать вхолостую
python3 gorzdrav.py hunt --dry-run

# 4. Поставить в крон (холостой режим), подождать минимум 30 циклов
#    */2 * * * * cd /путь/к/gorzdrav-slot-hunter && python3 gorzdrav.py hunt >> ~/.local/state/gorzdrav/cron.log 2>&1

# 5. Включить боевой режим для цели
python3 gorzdrav.py arm <имя цели>

# Состояние, выключение
python3 gorzdrav.py status
python3 gorzdrav.py disarm <имя цели>                 # вернуть цель в холостой режим
python3 gorzdrav.py disarm                            # рубильник: остановить всё
```

Ручная запись на конкретный талон: `python3 gorzdrav.py book --lpu 1 --doctor 3028 --slot <id> --yes`.

### Поля цели

| Поле | Что значит |
|---|---|
| `name` | имя цели |
| `patient` | ключ пациента из creds.json (по умолчанию `me`) |
| `lpu`, `speciality` | id поликлиники и специальности |
| `doctors` | список id врачей; пусто — любой |
| `dates` | `["с", "по"]` в формате `YYYY-MM-DD`; пусто — любые |
| `weekdays` | дни недели 1–7 (пн = 1); пусто — любые |
| `time` | `["09:00", "18:00"]`; пусто — любое |
| `earlier_than` | `"2026-12-01T00:00"`: только раньше этого момента |
| `min_lead_minutes` | не брать талон, до которого меньше N минут (по умолчанию 180) |
| `mode` | `dry` — только сообщать; боевой режим включается командой `arm` |

## Безопасность и проверка TLS

Сайт подписан сертификатом российского удостоверяющего центра (Минцифры), которого нет в системных
хранилищах. Корневой сертификат лежит в `certs/` и взят с gu-st.ru. При каждом запуске скрипт сверяет
его отпечаток SHA-256 (`D2:6D:2D:02:…:CA:8E:CF:31`). Проверка TLS не отключается нигде.
